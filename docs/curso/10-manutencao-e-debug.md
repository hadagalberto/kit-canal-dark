# 10 · Manutenção e debug

**Objetivo:** Resolver sozinho o que quebra.

## Aulas

1. Ler logs: docker compose logs, rodadas.jsonl, pasta work/
2. Feeds que mudam, sites que bloqueiam, APIs que mudam de versão
3. Atualizar o kit (git pull + docker compose build)
4. Backup do volume dados
5. Rodar mais de um canal no mesmo PC (um .env por pasta, um CANAL por compose)

Quebrar uma coisa de propósito (feed errado, chave inválida) e achar a causa pelo log.
